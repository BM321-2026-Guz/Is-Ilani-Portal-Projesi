# İş İlanı Portalı

Üniversite öğrencileri için staj ve yarı zamanlı iş ilanı portalı.

İşe alım uzmanı ilan yayınlar. Öğrenci portföyüyle başvurur. İşe alım uzmanı adayı kısa listeye alır.

## Yığın

MongoDB, Express, React, Node.js. Kimlik doğrulama JWT. Lisans MIT.

Şekil, modüler tek servistir: bir web istemcisi, bir API, bir veritabanı. Sözleşme koddan önce `docs/openapi.yaml` dosyasındadır.

Dallar: `main`, `develop`, `feature/<iş>`. Kural `docs/git-flow.md` dosyasındadır.
